# Thunderstore icon

Before packaging, add `icon.png` to this directory.

- Exactly 256×256 pixels.
- PNG format.
- Use original artwork you own or have permission to redistribute.
- Suggested treatment: a simple mountain silhouette, mischievous eyes, and the letters “PTM”; keep details readable at 64×64.
- Do not reuse PEAK logos, screenshots, game textures, extracted assets, or third-party artwork without permission.

`package.ps1` intentionally stops if the icon is missing so an invalid or rights-encumbered archive is not produced.
