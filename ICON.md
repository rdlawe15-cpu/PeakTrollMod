# Thunderstore icon

Thunderstore requires a square `icon.png` in the package root.

Recommended placeholder brief:

- 256×256 PNG.
- Deep navy translucent panel background.
- White mountain/peak silhouette.
- Large purple `T` or compact `TROLL` wordmark.
- Cyan rim light and no tiny text.
- Use only original artwork; do not extract PEAK logos or game textures.

Save the final file as `icon.png` next to `manifest.json` before running `package.ps1`.
